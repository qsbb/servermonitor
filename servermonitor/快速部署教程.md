# servermonitor 快速部署教程

这是一份复制命令即可跑通的部署教程，适合第一次安装。

## 0. 你需要准备什么

- 一台正在运行的 TRSS-Yunzai
- Yunzai 对外或对内可访问的 HTTP 地址，例如：`http://192.168.1.10:2536`
- 需要被监控的服务器安装 Node.js 18+

变量约定：

```bash
YUNZAI_DIR=/path/to/Yunzai
YUNZAI_URL=http://192.168.1.10:2536
```

请把上面的路径和地址替换成你的实际值。

## 1. 安装 Yunzai 插件

### 方式 A：从 GitHub 安装

在 Yunzai 所在机器执行：

```bash
cd /tmp
rm -rf servermonitor-src
git clone https://github.com/qsbb/servermonitor.git servermonitor-src

cd "$YUNZAI_DIR"
rm -rf plugins/servermonitor
cp -r /tmp/servermonitor-src/servermonitor plugins/servermonitor
```

> 注意：仓库根目录里包含 `servermonitor/` 插件目录，所以不要直接 clone 到 `plugins/servermonitor`，否则会变成 `plugins/servermonitor/servermonitor/index.js`。

### 方式 B：下载 Release 压缩包

```bash
cd /tmp
rm -rf servermonitor-* servermonitor.tar.gz
curl -L -o servermonitor.tar.gz https://github.com/qsbb/servermonitor/archive/refs/tags/v0.1.2.tar.gz
tar -xzf servermonitor.tar.gz

cd "$YUNZAI_DIR"
rm -rf plugins/servermonitor
cp -r /tmp/servermonitor-0.1.2/servermonitor plugins/servermonitor
```

## 2. 重启 Yunzai

```bash
cd "$YUNZAI_DIR"
pnpm start
```

如果你用的是 systemd / pm2 / screen / docker 管理 Yunzai，请按你的原方式重启。

## 3. 先验证本机状态

在 QQ 里发送：

```text
#服务器状态
```

预期结果：

- 没有添加任何服务器时，会显示 Yunzai 所在机器的 `本机` 状态
- 图片渲染失败时，会返回文本状态，不会静默

## 4. 添加一台远程服务器

主人私聊机器人：

```text
#服务器状态添加 web-01
```

机器人会返回类似内容：

```text
已添加服务器【web-01】
token：sm_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
上报接口：http://127.0.0.1:2536/servermonitor/report
请在服务器的 agent 目录中执行以下命令：
node agent.mjs --name "web-01" --token "sm_xxx" --report-url "http://127.0.0.1:2536/servermonitor/report" --interval "10"
```

如果上报接口是 `127.0.0.1` 或 `localhost`，请改成远程服务器能访问到的地址，例如：

```text
http://192.168.1.10:2536/servermonitor/report
```

## 5. 部署服务器上的 agent 模块

下面以 Linux 服务器 `/opt/servermonitor/agent` 为例。

### 5.1 复制 agent

从 Yunzai 机器复制：

```bash
scp -r "$YUNZAI_DIR/plugins/servermonitor/agent" root@web-01:/opt/servermonitor/agent
```

或直接在目标服务器上 clone：

```bash
mkdir -p /opt/servermonitor
cd /tmp
rm -rf servermonitor-src
git clone https://github.com/qsbb/servermonitor.git servermonitor-src
cp -r /tmp/servermonitor-src/servermonitor/agent /opt/servermonitor/agent
```

### 5.2 安装依赖

在目标服务器执行：

```bash
cd /opt/servermonitor/agent
npm install
```

### 5.3 本地采集测试

```bash
node agent.mjs \
  --name web-01 \
  --token sm_xxx \
  --report-url "$YUNZAI_URL/servermonitor/report" \
  --dry-run
```

看到 JSON 输出说明采集正常。

### 5.4 上传一次测试

```bash
node agent.mjs \
  --name web-01 \
  --token sm_xxx \
  --report-url "$YUNZAI_URL/servermonitor/report" \
  --once
```

正常会输出：

```text
[servermonitor-agent] web-01 uploaded @ 2026-01-01T00:00:00.000Z
```

然后在 QQ 里发送：

```text
#服务器状态
```

应能看到 `本机` 和 `web-01` 两张卡片。

## 6. Linux 常驻运行：systemd

创建服务：

```bash
cat >/etc/systemd/system/servermonitor-agent.service <<'EOF'
[Unit]
Description=servermonitor agent
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
WorkingDirectory=/opt/servermonitor/agent
ExecStart=/usr/bin/node /opt/servermonitor/agent/agent.mjs --name web-01 --token sm_xxx --report-url http://192.168.1.10:2536/servermonitor/report --interval 10 --slow-interval 30
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF
```

启动：

```bash
systemctl daemon-reload
systemctl enable --now servermonitor-agent
systemctl status servermonitor-agent
```

查看日志：

```bash
journalctl -u servermonitor-agent -f
```

## 7. Linux 可选：Docker 运行 agent

在目标服务器执行：

```bash
cd /opt/servermonitor
docker build -t servermonitor-agent ./agent

docker run -d \
  --name servermonitor-agent \
  --restart always \
  --network host \
  --pid host \
  -v /proc:/host/proc:ro \
  -v /sys:/host/sys:ro \
  servermonitor-agent \
  node agent.mjs --name web-01 --token sm_xxx --report-url http://192.168.1.10:2536/servermonitor/report --interval 10
```

宿主机指标最完整的方式仍是 systemd 原生部署。

## 8. Windows 快速部署

1. 安装 Node.js 18+
2. 将 `servermonitor/agent` 复制到：`C:\servermonitor\agent`
3. 安装依赖：

```powershell
cd C:\servermonitor\agent
npm install
```

4. 测试上传：

```powershell
node agent.mjs --name win-01 --token sm_xxx --report-url http://192.168.1.10:2536/servermonitor/report --once
```

5. 用 NSSM 注册服务：

```powershell
nssm install servermonitor-agent "C:\Program Files\nodejs\node.exe" "C:\servermonitor\agent\agent.mjs" --name win-01 --token sm_xxx --report-url http://192.168.1.10:2536/servermonitor/report --interval 10
nssm set servermonitor-agent AppDirectory "C:\servermonitor\agent"
nssm start servermonitor-agent
```

## 9. macOS 快速部署

1. 安装 Node.js 18+
2. 放置 agent：

```bash
sudo mkdir -p /opt/servermonitor
sudo cp -r agent /opt/servermonitor/agent
cd /opt/servermonitor/agent
npm install
```

3. 测试上传：

```bash
node agent.mjs --name mac-01 --token sm_xxx --report-url http://192.168.1.10:2536/servermonitor/report --once
```

4. 需要常驻运行时使用 `launchd`，完整 plist 示例见 `部署文档.md`。

## 10. 常见问题速查

### 10.1 发送 `#服务器状态` 没反应

按顺序检查：

1. 插件目录是否为 `plugins/servermonitor/index.js`
2. 是否重启或热加载了 Yunzai
3. `config.yaml` 中是否有：

```yaml
public_status: true
include_local: true
```

4. Yunzai 控制台是否有插件加载错误
5. 渲染失败时应有文本兜底输出；如果连文本都没有，优先看命令正则是否被其他插件抢占

### 10.2 远程服务器一直离线

检查：

```bash
curl -i "$YUNZAI_URL/servermonitor/report"
```

`GET` 请求返回不是重点，重点是确认网络能通。随后检查：

- token 是否复制正确
- `--report-url` 是否是远端可访问地址
- agent 日志是否显示 uploaded
- `offline_timeout` 是否大于 agent `--interval`

### 10.3 图片不出来但有文本

说明插件命令和采集正常，问题在 Yunzai 渲染器。检查 Puppeteer / Chromium 依赖即可。

## 11. 升级

保留运行时配置：

```bash
cd "$YUNZAI_DIR"
cp plugins/servermonitor/config.yaml /tmp/servermonitor.config.yaml 2>/dev/null || true
cp -r plugins/servermonitor/data /tmp/servermonitor.data 2>/dev/null || true

rm -rf /tmp/servermonitor-src
git clone https://github.com/qsbb/servermonitor.git /tmp/servermonitor-src
rm -rf plugins/servermonitor
cp -r /tmp/servermonitor-src/servermonitor plugins/servermonitor

cp /tmp/servermonitor.config.yaml plugins/servermonitor/config.yaml 2>/dev/null || true
rm -rf plugins/servermonitor/data
cp -r /tmp/servermonitor.data plugins/servermonitor/data 2>/dev/null || mkdir -p plugins/servermonitor/data
```

然后重启 Yunzai。
