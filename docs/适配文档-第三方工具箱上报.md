# 第三方工具箱适配文档：上报到 TRSS-Yunzai servermonitor

## 1. 目标

让任何 Windows 工具箱/客户端按固定间隔把本机状态推送到 Yunzai 的 `servermonitor` 插件，插件端就能在 `#服务器状态` 里显示这台机器。

## 2. 接口

- 方法：`POST`
- 路径：`/servermonitor/report`
- Content-Type：`application/json`
- 认证头：`X-SM-Token`
- 建议间隔：10~20 秒一次，最长不要超过 30 秒，否则会被判定离线。
- 请求体大小上限：256 KB
- 单 token 限速：60 次/分钟；单 IP 240 次/分钟

示例：

```text
POST http://192.168.5.88:2536/servermonitor/report
X-SM-Token: sm_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Content-Type: application/json
```

## 3. token 怎么选

有两种方式：

1. **共享 token 自动注册**
   - 所有机器都可以用同一个 `shared_token`
   - 首次上报会按 `name` 自动注册
   - 每台机器必须使用不同的 `name`
2. **独立 token 手动绑定**
   - 在 Yunzai 主人私聊里发送：`#服务器状态添加 <名称>`
   - 用返回的独立 token 上报
   - 适合需要更严格隔离的场景

如果你现在只是想让工具箱先跑通，先用共享 token，并且把 `name` 改成独一无二的，例如 `toolbox-win-01`。

## 4. 请求体结构

```json
{
  "v": 1,
  "name": "toolbox-win-01",
  "agent_ts": 1710000000000,
  "os": {
    "platform": "windows",
    "distro": "Windows 11 Pro",
    "release": "22H2",
    "arch": "x64",
    "hostname": "DESKTOP-XXXX",
    "uptime": 123456
  },
  "cpu": {
    "model": "Intel Core i7-12700",
    "cores": 12,
    "usage": 37.5,
    "temp": 62,
    "power": null
  },
  "gpus": [
    {
      "model": "NVIDIA GeForce RTX 3060",
      "usage": 55,
      "temp": 65,
      "memUsed": 2.4,
      "memTotal": 12,
      "power": 120
    }
  ],
  "mem": {
    "used": 8.2,
    "total": 16,
    "swapUsed": null,
    "swapTotal": null
  },
  "net": {
    "iface": "Ethernet",
    "rxSec": 12.3,
    "txSec": 4.5,
    "rxTotal": 1024.5,
    "txTotal": 512.1
  },
  "disks": [
    { "mount": "C:\\", "used": 120.5, "total": 512 },
    { "mount": "D:\\", "used": 300, "total": 1000 }
  ],
  "load": [1.2, 1.1, 1.0]
}
```

字段说明：

- `v` 必须为 `1`
- `name` 服务器显示名，建议唯一，最多 32 字符，不要有空格和 `<>&"'`\`
- `agent_ts` 毫秒时间戳；没有就省略
- `os.*`、`cpu.*`、`mem.*`、`net.*` 可为 `null`
- `gpus`、`disks` 可为空数组
- 数值不要带单位字符串，只传数字
- 温度用摄氏度
- 显存/磁盘用 GB
- 速率用 MB/s

## 5. 最小可用请求

如果暂时只想跑通，先发这个也够：

```json
{
  "v": 1,
  "name": "toolbox-win-01",
  "os": {
    "platform": "windows",
    "hostname": "DESKTOP-XXXX"
  },
  "cpu": {
    "model": "Intel Core i7-12700",
    "usage": 30
  },
  "mem": {
    "used": 8,
    "total": 16
  },
  "disks": [
    { "mount": "C:\\", "used": 100, "total": 512 }
  ]
}
```

## 6. Windows 快速自测

PowerShell：

```powershell
$token = "sm_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
$body = @'
{
  "v": 1,
  "name": "toolbox-win-01",
  "os": {
    "platform": "windows",
    "hostname": "DESKTOP-XXXX"
  },
  "cpu": {
    "model": "Intel Core i7-12700",
    "usage": 30
  },
  "mem": {
    "used": 8,
    "total": 16
  },
  "disks": [
    { "mount": "C:\\", "used": 100, "total": 512 }
  ]
}
'@

Invoke-RestMethod -Uri "http://192.168.5.88:2536/servermonitor/report" -Method Post `
  -Headers @{ "X-SM-Token" = $token } `
  -ContentType "application/json" `
  -Body $body
```

成功时应返回：

```json
{ "ok": true, "name": "toolbox-win-01", "auto": true }
```

## 7. 常见错误与排查

| HTTP 状态 | 含义 | 排查 |
| --- | --- | --- |
| 200 | 成功 | 看返回 `name` 是否是你要的 |
| 202 | 成功但等待绑定 | 用返回的 `bind` 命令去 Yunzai 绑定 |
| 401 | token 无效 | 检查 `X-SM-Token` 是否完整 |
| 403 | name 冲突 | 改一个唯一的 `name` |
| 413 | 请求体太大 | 减少字段或缩短字符串 |
| 422 | 请求体格式不对 | 确认 `v:1`、JSON 合法、数值是数字 |
| 429 | 限速 | 降低上报频率 |
| 500 | 服务端错误 | 看 Yunzai 日志 |

## 8. 排查顺序

1. 在 Windows 上直接用上面的 PowerShell 测试一次。
2. 如果返回 200/202，说明接口没问题，问题在你工具箱自己的代码里。
3. 如果不是 200/202，把返回体和请求体发出来。
4. 在 Yunzai 所在机器查日志：

   ```bash
   tail -n 200 logs/command.$(date +%F).log | grep -i servermonitor
   ```

5. 在 Yunzai 里发送：

   ```text
   #服务器状态列表
   ```

   确认是否出现 `toolbox-win-01`。

## 9. Windows 采集建议

- CPU 使用率：`Get-CimInstance Win32_Processor | Select-Object LoadPercentage`
- 内存：`Get-CimInstance Win32_OperatingSystem | Select-Object TotalVisibleMemorySize,FreePhysicalMemory`
- 磁盘：`Get-CimInstance Win32_LogicalDisk -Filter "DriveType=3"`
- GPU：`Get-CimInstance Win32_VideoController`
- 网卡：`Get-NetAdapterStatistics`

## 10. 集成清单

- [ ] `POST` 到 `/servermonitor/report`
- [ ] `Content-Type: application/json`
- [ ] `X-SM-Token` 已带上
- [ ] `v` 是数字 `1`
- [ ] `name` 唯一且稳定
- [ ] 数值字段都是数字，不是字符串
- [ ] 上报间隔 ≤30 秒
- [ ] Yunzai 日志里能看到 `report accepted`
- [ ] `#服务器状态列表` 里能看到这台机器

## 11. 给对方/协作 agent 的提示词

你可以直接把下面这段发给他：

> 请按以下接口接入：
>
> `POST http://192.168.5.88:2536/servermonitor/report`
>
> 头：`X-SM-Token: <token>`，`Content-Type: application/json`
>
> 请求体必须是 JSON，至少包含：
>
> ```json
> {
>   "v": 1,
>   "name": "toolbox-win-01",
>   "os": { "platform": "windows", "hostname": "DESKTOP-XXXX" },
>   "cpu": { "model": "Intel Core i7-12700", "usage": 30 },
>   "mem": { "used": 8, "total": 16 },
>   "disks": [{ "mount": "C:\\", "used": 100, "total": 512 }]
> }
> ```
>
> 先用 PowerShell 的 `Invoke-RestMethod` 发一次，确认返回 `ok:true`。
> 然后再把这段逻辑写进工具箱，间隔 10 秒一次。
> 如果返回 403，说明 `name` 冲突，换个名字。
> 如果返回 401，说明 token 错。
> 如果返回 422，说明 JSON 结构不对。
> 先跑通最小请求，再补 GPU/网络/更多磁盘。
