# Servermonitor 最终开发方案

> 本文档是三组对抗性审查 + 前两轮盲测结果的合并修复计划。
> 目标版本：`v0.1.15`
> 分批落地，先修“会直接把服务打挂 / 配置弄丢 / 数据不可信”的问题。

---

## 1. 本轮修复目标

1. 阻断匿名上报路径上的资源耗尽、绑定劫持、共享 token 滥用。
2. 修复 v0.1.13/14 引入的三处安装/更新回归。
3. 修复 agent 采集超时、Linux 功耗/温度 symlink 误判。
4. 修复 UI 缺数据显示、双列等高、重复数字、对比度。
5. 保持现有命令和部署方式兼容，不引入破坏性迁移。

---

## 2. 第一批：安全与稳定性

### 上报接口
- 只对精确上报路径放行 `skip_auth`，不再整段前缀豁免。
- 上报请求加进程内速率限制，按 token + IP 限频。
- 上报 body 增加大小上限。
- 快照字段统一截断：
  - 字符串 ≤ 128 字符
  - disks ≤ 16
  - gpus ≤ 8
- `pending.json` 写入节流，避免每个未绑定请求都全量落盘。

### token 与自动注册
- 共享 token 不能写入已存在的同名服务器。
- 共享 token 自动注册增加服务器总数上限。
- 待绑定列表只能在私聊查看。
- 绑定时如果同名服务器已存在且 token 不同，不允许静默覆盖。
- 共享 token 比较改为常量时间比较。

### 配置写入
- `updateConfig()` 加进程内互斥。
- 临时文件名加入随机后缀，避免并发覆盖。
- 配置解析失败不再静默重置为空配置；保留最近一次可用配置。

---

## 3. 第二批：agent 与安装器

### agent
- 所有 `systeminformation` 调用加超时。
- 单项采集失败返回 `null`，不能拖垮整次上报。
- `/sys/class/powercap/intel-rapl:*` 兼容 symlink。
- `/sys/class/thermal/thermal_zone*` 读取 `type`，避免把 GPU/ACPI 温度当 CPU 温度。
- Windows 服务模式显式 `run`，空 argv 且非 TTY 时不进入交互菜单。

### 安装器
- Linux systemd 读写 `Environment="K=V"` 时统一剥引号。
- Docker `.env` 读取时剥引号，写入时不再叠引号。
- Windows NSSM 启动命令追加 `run`。
- 更新流程改为“先准备新目录，成功后再切换”，失败时保留旧服务。
- 交互安装器同步修复 systemd 环境变量解析。

---

## 4. 第三批：UI 与展示

- 双列网格去掉强制等高，改为 `align-items: start`。
- CPU/GPU 缺数据时显示 `—`，不再误显示 `0.0%`。
- CPU/内存/磁盘/GPU 文本去掉重复数字。
- 磁盘挂载点、GPU 型号允许换行，不再静默截断。
- 小字号对比度提高，离线卡片避免二次变暗。
- 无 GPU 机器收成单行元信息，不占大卡片。
- 磁盘超过 8 个时显示 `+N`。
- 详情页补充 CPU 核心、swap、网卡信息。
- 单页时不显示分页角标。

---

## 5. 文档修正

- 验证上报接口改为 POST 示例。
- Windows 文档改为下载后执行，不再推荐 `irm | iex`。
- Docker 文档明确挂载、权限和更新方式。
- Release 构建流程恢复并固定到仓库。
- 移除或实现 `show_ip_in_image`。
- `#服务器状态帮助` 增加“待绑定”。

---

## 6. 回归验证

每批修复后执行：

1. `node --check` 全部 JS/MJS。
2. `bash -n` 全部安装脚本。
3. 启动一个临时上报接口，模拟：
   - 正常 agent 上报
   - 共享 token 自动注册
   - 共享 token 写已有同名服务器
   - 超大 / 超长 / 超量快照
   - 并发自动注册
4. 渲染 1 / 3 / 4 / 5 台服务器卡片。
5. 检查离线、无 GPU、无磁盘、无网络、超长名称。
6. 重跑 Linux / Docker / Windows 安装脚本，确认更新模式读回旧 token。
